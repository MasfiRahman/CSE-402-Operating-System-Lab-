\section{Problem Statement}
Write a Python program to implement the FIFO (First-In, First-Out) page replacement algorithm using a predefined reference string. Execute the program with frame sizes of 3 and 4 separately, calculate the total page hits, page faults, hit ratio, and fault ratio for each case, and compare the results to analyze the effect of frame size on paging performance.

\textbf{Reference string:} [1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5]

\section{Source Code}
\begin{lstlisting}[caption={Python implementation of FIFO Page Replacement Algorithm}]
def fifo_page_replacement(reference_string, frame_size):
    frames = []
    page_faults = 0
    page_hits = 0

    for page in reference_string:
        if page in frames:
            page_hits += 1
        else:
            page_faults += 1
            if len(frames) == frame_size:
                frames.pop(0)  # Remove the oldest page (FIFO)
            frames.append(page)

    total_references = len(reference_string)
    hit_ratio = page_hits / total_references
    fault_ratio = page_faults / total_references

    return page_hits, page_faults, hit_ratio, fault_ratio

reference_string = [1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5]

print("Frame Size = 3")
hits3, faults3, hit_r3, fault_r3 = fifo_page_replacement(reference_string, 3)
print(f"Page Hits: {hits3}, Page Faults: {faults3}")
print(f"Hit Ratio: {hit_r3:.2f}, Fault Ratio: {fault_r3:.2f}\n")

print("Frame Size = 4")
hits4, faults4, hit_r4, fault_r4 = fifo_page_replacement(reference_string, 4)
print(f"Page Hits: {hits4}, Page Faults: {faults4}")
print(f"Hit Ratio: {hit_r4:.2f}, Fault Ratio: {fault_r4:.2f}")
\end{lstlisting}

\section{Comparison within FIFO Page Replacement Algorithm with frame size 3 and 4}
In this experiment, the FIFO (First-In, First-Out) page replacement algorithm was tested using frame sizes of 3 and 4 with the same reference string. Surprisingly, the number of page faults increased from 9 to 10 when the frame size was increased from 3 to 4. This phenomenon is known as Belady's Anomaly, which can occur in the FIFO page replacement algorithm. It happens because FIFO replaces pages based on their arrival order rather than how frequently or recently they are used. Increasing the number of frames can change the replacement order, causing pages that are needed again later to be removed from memory. Consequently, the system may experience more page faults even though additional frames are available. This experiment demonstrates that increasing the frame size does not always improve paging performance when using the FIFO algorithm.
